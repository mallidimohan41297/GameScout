# GameScout 🎮

I started this because I was bored and couldn't decide what game to play.

I wanted to find something based on things I actually care about — genre, difficulty, single-player or multiplayer, shooter or not, platform, and so on.

So I made GameScout.

It uses the RAWG API for game data and gives me a simple way to browse and filter games instead of going through random game lists.

## What it does

- Browse games
- Search for games
- Filter games based on different preferences
- View game details
- Open external review/rating sources
- A small 3D section in the UI

The difficulty shown in the app is an estimate made for this project, not an official RAWG value.

## Built with

- Next.js
- React
- TypeScript
- Tailwind CSS
- Three.js / React Three Fiber
- RAWG API
